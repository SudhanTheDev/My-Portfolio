## 💻 Run the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/Sujan-Nepal/portfolio.git
```

### 2. Enter the project folder

```bash
cd portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create an `.env.local` file inside the main project folder:

```env
VARIABLE_NAME=your_private_value
```

Use an `.env.example` file to show the required variable names without exposing real values:

```env
VARIABLE_NAME=
```

### 5. Start the development server

```bash
npm run dev
```

### 6. Open the website

```text
http://localhost:3000
```

---

## 🔐 Environment Security

Sensitive environment files are protected through `.gitignore`.

```gitignore
.env
.env.local
.env*.local
```

Never upload:

```text
❌ API keys
❌ Authentication secrets
❌ Database passwords
❌ Private access tokens
❌ Email credentials
❌ Private service configuration
```

An `.env.example` file should contain only empty or fake placeholder values.

If a real secret is accidentally committed:

1. Revoke or regenerate the exposed secret.
2. Remove the secret from the repository.
3. Replace it with a new secure value.
4. Check the repository history for exposure.
